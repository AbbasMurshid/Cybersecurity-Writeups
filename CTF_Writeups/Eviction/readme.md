# 🛡️ TryHackMe: Eviction

**Category:** Cyber Defense Frameworks / Blue Team
**Focus:** Threat Intelligence & MITRE ATT&CK

## 📄 Overview
This repository contains my writeup for the **Eviction** room on TryHackMe. This challenge simulates a real-world defensive scenario where I acted as a SOC Analyst for "E-Corp" to investigate an imminent threat from **APT28** (Fancy Bear).

## 🎯 Project Goals
* Analyze global threat intelligence reports.
* Map adversary behaviors to the **MITRE ATT&CK Framework**.
* Predict the attacker's next steps in the Cyber Kill Chain (from Initial Access to Exfiltration).

## 🧠 Key Skills Learned
* **Threat Mapping:** How to use the MITRE Navigator to visualize attacker TTPs.
* **Behavioral Analysis:** Identifying "Living off the Land" binaries like `rundll32` and `powershell`.
* **Persistence Mechanisms:** Understanding how attackers use Registry Run Keys to survive reboots.
